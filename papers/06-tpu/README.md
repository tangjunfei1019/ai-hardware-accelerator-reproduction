# 数据中心张量处理单元的性能分析

## 原文信息

- 原文标题：In-Datacenter Performance Analysis of a Tensor Processing Unit
- 作者：Norman P. Jouppi、Cliff Young、Nishant Patil、David Patterson 等
- 年份与发表处：2017，ISCA 2017

## 核心方法

- 领域专用架构：TPU 的核心是 256×256 的 8 位脉动阵列矩阵乘法单元，权重从一侧流入、激活从另一侧流入，部分和在阵列内流动，单周期可完成大量乘加。
- 大片上软件管理存储：约 28 MiB 片上存储（含统一缓冲与累加器），由软件显式管理，而不是依赖通用 CPU 的缓存、乱序、预取等时变优化；这对推理的 99 分位延迟更友好。
- 量化推理：训练用浮点、推理用 8 位整数，在精度损失可控的前提下换取算力密度与能效；指令集是类 CISC 的专用指令（读主机内存、读权重、矩阵乘/卷积、激活等）。
- 目标不是通用计算，而是数据中心 95% 的推理负载（MLP、CNN、LSTM），为此牺牲通用性。

## 核心效果

- 论文报告（arXiv:1704.04760 摘要，以原文为准）：峰值约 92 TOPS（8 位），片上存储约 28 MiB；与同期 Haswell CPU 和 Nvidia K80 GPU 相比，平均约 15 倍至 30 倍更快，TOPS/W 约 30 倍至 80 倍更高。
- 瓶颈分析同样重要：部分应用利用率低，且多为访存受限；若把 TPU 的内存换成 K80 的 GDDR5，论文估算性能与能效还会进一步提升。
- 延迟结论：确定性执行模型对推理服务的尾延迟比 CPU/GPU 的时变优化更友好。

## 复现要点

- 复现目标：用脉动阵列模拟矩阵乘法，测量阵列规模、数据流入节奏与利用率的关系，验证“权重/激活流动方式决定利用率”。
- 要测量：不同矩阵形状下的 PE 利用率、流水线填充与排空开销、量化（8 位）前后的误差。
- 不会与原文芯片一致的地方：真实 TPU 的时钟、功耗、数据中心部署条件、专有指令与软件栈；骨架只验证脉动阵列的计算正确性与利用率趋势。
