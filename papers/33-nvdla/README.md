# NVDLA：NVIDIA 深度学习加速器（开放架构）

## 原文信息

- 原文标题：NVDLA Primer（NVIDIA 官方架构文档）；系统为 NVIDIA Deep Learning Accelerator，2017 年开源
- 中文标题：NVDLA：NVIDIA 深度学习加速器（开放架构）
- 作者/来源：NVIDIA；最初为 Xavier SoC 设计，后作为可参数化架构开源
- 年份与发表处：开源发布 2017–2018 年
- 上游仓库：https://github.com/nvdla/hw

> 先说明：这是一篇开放系统条目，而不是传统会议论文，标注如此是为了不把它误认为一篇普通会议论文。

## 核心方法

- 模块化推理流水线：卷积核（CDMA 把数据流式送入卷积缓冲、CSC 序列器、CMAC 乘累加阵列、CACC 部分和累加），随后是 SDP（激活/偏置/批归一化/逐元素运算）、PDP（池化）、CDP（通道归一化），外加 BDMA 与 RUBIK 做数据搬运与重排。
- 两种编程模式：独立模式（各模块分别配置）与融合模式（各模块经小 FIFO 流水，省去一次访存往返）。
- 仓库中的 `nvdlav1` 分支是不可配置的“全精度”版本，固定为 2048 个 8-bit MAC 或 1024 个 16-bit MAC；master 分支为可配置版本。

## 核心效果

- 影响：NVDLA 是第一个工业级、开放发布的深度学习推理加速器架构——一个完整、模块化、可扩展的设计，其他公司与开放 SoC 项目（包括 RISC-V SoC 平台）可以真正集成，而不是只有论文的设计。
- 这里不引用单一加速比，因为性能取决于所选配置（小/大、8-bit/16-bit）；权威来源是 Primer 与仓库 `perf/` 中的性能估计电子表。

## 复现要点

- 复现目标：用流水线阶段模拟一次推理：卷积 → 激活 → 池化，理解各模块如何串联。
- 要测量：各阶段的输出尺寸与数值变化；不要把骨架输出当作原文性能数字。
- 不会与原文工具一致的地方：真实 Verilog RTL、SystemC C 模型、trace 播放测试、综合面积与功耗；骨架只演示流水线思想。
