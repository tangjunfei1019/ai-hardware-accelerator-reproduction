# Cambricon：面向神经网络的指令集架构

## 原文信息

- 原文标题：Cambricon: An Instruction Set Architecture for Neural Networks
- 作者：Shaoli Liu、Zidong Du、Jinhua Tao 等
- 年份与发表处：2016，ISCA 2016

## 核心方法

- 问题定位：通用 ISA（x86、MIPS、GPGPU）为神经网络付出了过多的灵活性开销，而固定功能的加速器又只能覆盖少数几种网络；Cambricon 要在两者之间找一个领域专用的平衡点。
- 指令集设计：load-store 架构，集成标量、向量、矩阵、逻辑、数据搬运与控制指令；基于对多种神经网络算法的共性分析，抽出共享的计算原语，而不是为每种网络单独做硬件。
- 覆盖面是评价核心：同一套指令要能表达卷积、池化、全连接、归一化等多种算子，代码密度要高于通用 ISA，同时硬件开销相对专用加速器可控。
- 后续 Cambricon-X（稀疏）、Cambricon-S（不规则稀疏的软硬协同）等工作，都是在这一 ISA 思想上的延伸，但本篇总结以 2016 年 ISA 论文为准。

## 核心效果

- 论文报告（以原文为准）：在 10 种代表性且不同的神经网络算法上，Cambricon 表现出较强的表达能力，代码密度高于 x86、MIPS 与 GPGPU 等通用 ISA。
- 与当时最先进的 DaDianNao（仅能覆盖 3 种神经网络算法）相比，基于 Cambricon 的原型在 TSMC 65 nm 下仅带来可忽略的延迟/功耗/面积开销，同时覆盖面扩展到 10 种基准。
- 关键结论不是单点速度，而是“通用性 + 效率”的 trade-off：领域专用 ISA 可以在不牺牲太多效率的前提下，显著扩大加速器的适用范围。

## 复现要点

- 复现目标：设计一个极小领域专用指令解释器，支持向量/矩阵原语，验证同一套指令能表达卷积、全连接、池化等不同算子。
- 要测量：表达不同算子所需的指令数（代码密度对比）、指令覆盖的算子种类、解释器执行的 MAC 数。
- 不会与原文芯片一致的地方：真实指令编码、流水线、硬件面积与功耗；骨架只验证 ISA 层面的表达能力。
