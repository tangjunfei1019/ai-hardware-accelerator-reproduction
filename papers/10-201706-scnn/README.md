# SCNN：面向压缩稀疏卷积神经网络的加速器

## 原文信息

- 原文标题：SCNN: An Accelerator for Compressed-Sparse Convolutional Neural Networks
- 作者：Angshuman Parashar、Minsoo Rhu、Anurag Mukkara 等
- 年份与发表处：2017，ISCA 2017

## 核心方法

- 同时利用权重稀疏与激活稀疏：传统稠密加速器对零值也做乘法，SCNN 只对非零权重与非零激活做有效计算，跳过其余部分。
- 压缩表示：权重与激活都用压缩格式存储与传输，减少片上/片外数据量；计算时用坐标信息还原非零元素的位置，再做乘积累加。
- 核心硬件结构：乘法器阵列 + 散射累加器（scatter accumulator）阵列。乘积结果的位置是不规则的，散射累加器负责把它们正确累加到对应的输出位置，同时保持高并行度。
- 后处理单元（PPU）处理非线性、池化与输出压缩，保证输出激活仍以压缩形式进入下一层，形成层与层之间的稀疏闭环。

## 核心效果

- 论文报告的代表性结论（以原文为准）：相对稠密卷积加速器，SCNN 在性能上约 2.7 倍、能效上约 2.3 倍的提升；具体倍数随网络稀疏度变化，稀疏度越高收益越大。
- 对比基线要分清：论文同时对比了传统稠密加速器（DCNN）与优化后的稠密加速器（DCNN-opt），不同基线下的倍数不同，引用时必须注明基线。
- 在低密度层上，加速比可进一步上升；但稀疏带来的不规则累加与负载不均衡，也是 SCNN 必须解决的代价，不能只看峰值倍数。

## 复现要点

- 复现目标：实现压缩稀疏卷积：只对非零权重与非零激活做乘法，用散射累加把结果累加到正确输出位置，对比稠密卷积的 MAC 数。
- 要测量：稀疏度、跳过的 MAC 比例、散射累加的冲突/负载不均衡、不同稀疏度下的加速比曲线。
- 不会与原文芯片一致的地方：真实 PE 阵列时序、HLS 综合后的面积与功耗、片上网络拥塞；骨架只验证稀疏计算的正确性与节省量。
