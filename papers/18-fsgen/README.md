# FSGen：面向大模型应用的敏捷融合稀疏加速器生成器

## 原文信息

- 原文标题：FSGen: Agile Fused and Sparse Accelerator Generator with Accurate Power Model for LLM Applications
- 中文标题：FSGen：面向大模型应用的敏捷融合稀疏加速器生成器与精确功耗模型
- 作者：Jay Zhe-An Mok、Qijun Zhang、Zhiyao Xie（香港科技大学）
- 年份与发表处：2026，DAC 2026（第 63 届 ACM/IEEE 设计自动化会议，2026 年 7 月，美国长滩）；DOI: 10.1145/3770743.3804052；arXiv:2608.09252

## 核心方法

- 融合与稀疏的数据流表示：用统一表示描述稀疏与融合算子的数据流，支持对融合数据流与稀疏模式的完整可配置。
- Chisel RTL 生成器：从配置直接生成 RTL，而不是只给仿真模型；同时提供早期基于机器学习的 PPA（功耗/性能/面积）估计。
- 面向 LLM：融合（例如注意力与前后算子融合）减少片外访存，稀疏跳过零值计算，两者结合服务大模型推理。

## 核心效果

- 论文报告（以原文为准）：相对已有工作，在相似 PPA 下约 1.4 倍功耗效率或约 10 倍加速；另有片段给出约 58 倍的综合品质因数（figure of merit），引用该数字时请以原文定义为准。
- 意义：与 OSCAR 同属一个团队的生成器路线，但 FSGen 专攻 LLM 的“融合 + 稀疏”组合——2026 年大模型加速器从通用 GEMM 走向算子级协同设计的代表。

## 复现要点

- 复现目标：模拟融合（跳过中间结果写回）与稀疏（跳过零值）对访存量与计算量的联合削减。
- 要测量：融合前后的片外流量、稀疏度与有效 MAC 数、两者的乘法效应。
- 不会与原文工具一致的地方：真实 Chisel 生成、稀疏编码硬件、PPA 模型拟合；骨架只验证融合与稀疏的收益算术。
