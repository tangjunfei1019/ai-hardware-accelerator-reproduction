# PIMSIM-NN：面向存内处理加速器的基于指令集架构的仿真框架

## 原文信息

- 原文标题：PIMSIM-NN: An ISA-based Simulation Framework for Processing-in-Memory Accelerators
- 中文标题：PIMSIM-NN：面向存内处理加速器的基于指令集架构的仿真框架
- 作者：Xinyu Wang、Xiaotian Sun、Yinhe Han、Xiaoming Chen
- 年份与发表处：DATE 2024（2024-03-25，Late Breaking Results）
- arXiv / DOI：arXiv:2402.18089；DOI 10.23919/DATE58400.2024.10546788

## 核心方法

- 提出面向神经网络的存内处理（PIM）专用指令集（ISA）、配套编译器与周期精确的可配置仿真器：编译器把神经网络描述转成指令序列，仿真器按架构配置对指令做周期精确评估，给出延迟、功耗与能耗。
- 用 ISA 把软件算法与硬件架构解耦：同一套指令可以在不同架构配置下评估，便于比较软硬件优化的效果；仿真器采用事件驱动仿真，对硬件并行有更好支持。
- 仿真器假设芯片由多核经片上网络（NoC）连接，每个核类似 RISC 处理器，含标量、向量、矩阵与传输四类执行单元，其中矩阵单元由 RRAM 交叉阵列构成，高效执行矩阵-向量乘。
- 仿真器输入为三类文件：架构配置文件、NoC 配置文件与程序指令文件；新指令需搭配 pimcomp-nn 编译器由 ONNX 模型生成。

## 核心效果

- 论文报告（以原文为准）：框架提供 ISA、编译器与周期精确仿真器三件套，支持对 PIM 加速器做可配置的性能与功耗评估；本文不把骨架的指令计数当作原文结果。
- 上游自带 ResNet-18 示例输出（模拟器估计，非硅片实测）：64 核配置下约 40 samples/s、平均延迟 25 ms，仿真器执行约 59 秒。
- 峰值性能：未给出可比的峰值数字。

## 复现要点

- 复现目标：先跑上游仓库的最小例子，确认核心机制可工作；再跑论文配置，对照原文基线与方法描述。
- 要测量：正确性（输出趋势）、关键配置变化带来的趋势，而非只看单一加速比。
- 不会与原文一致的地方：工艺、器件参数、仿真器版本与基线配置差异都会改变绝对数字；骨架只演示思想。
