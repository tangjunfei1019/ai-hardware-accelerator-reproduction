# EIE：面向压缩深度神经网络的高效推理引擎

## 原文信息

- 原文标题：EIE: Efficient Inference Engine on Compressed Deep Neural Network
- 作者：Song Han、Xingyu Liu、Huizi Mao 等
- 年份与发表处：2016，ISCA 2016

## 核心方法

- 先压缩，再加速：Deep Compression 三步——剪枝（去掉冗余连接）、训练量化（权重共享，多个连接共用同一权重值）、霍夫曼编码——把大模型压到能放进片上 SRAM。
- EIE 直接在压缩格式上做推理：权重以 CSC（压缩稀疏列）格式存储，PE 阵列并行做稀疏矩阵-向量乘法，跳过零权重与零激活，避免为零值浪费算力与带宽。
- 关键机制：权重共享（查码本得到真实权重）、相对索引、前导零检测（找到下一个非零激活），以及每个 PE 只存网络的一个分区，天然并行。
- 能效来源是分层相乘的：SRAM 代替 DRAM、稀疏跳过、权重共享、跳过 ReLU 零激活，每一步都省一部分。

## 核心效果

- 论文报告（arXiv:1602.01528 摘要，以原文为准）：在压缩网络上约 102 GOPS，相当于未压缩网络约 3 TOPS；AlexNet 全连接层约 1.88×10^4 帧/秒，功耗仅约 600 mW。
- 分解收益：DRAM→SRAM 约 120 倍节能；稀疏约 10 倍；权重共享约 8 倍；跳过 ReLU 零激活再约 3 倍；相对 CPU/GPU，速度约 189 倍 / 13 倍，能效约 24,000 倍 / 3,400 倍（对照条件与基准以原文为准）。
- 相对 DaDianNao，论文报告吞吐约 2.9 倍、能效约 19 倍、面积效率约 3 倍。

## 复现要点

- 复现目标：实现 CSC 稀疏矩阵-向量乘法 + 权重共享码本，验证跳过零值带来的 MAC 节省与精度保持（在小模型上）。
- 要测量：剪枝率、量化码本大小、跳过的 MAC 比例、量化前后精度变化、SRAM 容量需求。
- 不会与原文芯片一致的地方：真实 PE 阵列时序、45 nm/28 nm 功耗、霍夫曼解码硬件；骨架只验证算法与稀疏计算的正确性。
