# DaDianNao：机器学习超级计算机

## 原文信息

- 原文标题：DaDianNao: A Machine-Learning Supercomputer
- 作者：Yunji Chen、Tao Luo、Shaoli Liu 等
- 年份与发表处：2014，MICRO 2014（最佳论文）

## 核心方法

- 从 DianNao 的单芯片扩展为多芯片：多个计算片（tile）围绕片上 eDRAM 组织，每个 tile 有自己的权重存储，整个模型尽量放在片上，避免反复走片外 DRAM。
- 利用神经网络层的可分性：不同 tile 处理不同的输出神经元 / 滤波器，激活以广播方式分发，权重留在本地，局部性好，可扩展性好。
- 存储与计算的比例是设计中心：与其堆更多乘法器，不如先把模型装进片上存储，再谈算力；这对大模型尤其重要。
- 同样使用 16 位 / 32 位定点、NFU 式计算单元和分块思想，但规模与互连是新的挑战。

## 核心效果

- 论文报告：多芯片聚合片上存储后，大模型推理不再被片外带宽卡住，相对 CPU/GPU 有显著加速；具体倍数随模型、规模与对照基线变化，复现时请以原文 PDF 的实验表为准，本总结不搬运二手倍数。
- 关键结论是可扩展性：增加芯片数量时，片上模型容量与计算能力可以同步扩展，而不是单芯片的线性瓶颈。
- 面积与功耗的绝对数字依赖 28 nm 工艺与 eDRAM 实现，软件骨架无法复现。

## 复现要点

- 复现目标：模拟多 tile 划分：输出通道分给不同 tile，权重本地存储，激活广播，统计片外访问量随 tile 数与模型大小的变化。
- 要测量：片外读取量、广播量、负载均衡（各 tile 的 MAC 数差异）、tile 数翻倍时的加速比与边际收益。
- 不会与原文芯片一致的地方：片间互连延迟、eDRAM 带宽与功耗、真实时钟频率。
