# DianNao：面向普适机器学习的小面积高吞吐加速器

## 原文信息

- 原文标题：DianNao: A Small-Footprint High-Throughput Accelerator for Ubiquitous Machine-Learning
- 作者：Tianshi Chen、Zidong Du、Ninghui Sun 等
- 年份与发表处：2014，ASPLOS 2014（最佳论文）

## 核心方法

- 把神经网络计算抽象为稠密线性代数：神经功能单元（NFU）由乘法器树、加法树和非线性激活三段流水组成，支持 16 位定点运算。
- 存储层次是关键：输入缓冲 NBin、输出缓冲 NBout、权重缓冲 SB 各自独立，因为输入、权重、输出的访问模式不同；再用分块（tiling）把大层切成适合片上缓冲的小块，配合预取掩盖访存延迟。
- 控制用精简的专用指令，而不是通用 CPU 的复杂控制流；同一 NFU 以时间复用的方式处理多个神经元，面积小，适合嵌入式场景。
- 设计目标不是追求单点峰值，而是用小面积和低功耗拿到可用的神经网络吞吐。

## 核心效果

- 论文以 SIMD 基线为对照，报告了数量级的性能与能效提升；不同讲义转述的倍数口径不同，复现时请以原文 PDF 的实验表为准，不要直接引用二手倍数。
- 本骨架不复现原文的绝对面积与功耗数字，因为那需要 65 nm 工艺库与综合流程，软件骨架无法给出。
- 关键可验证结论是定性的：分块 + 三类独立缓冲 + 定点 NFU，能显著降低片外访存压力。

## 复现要点

- 复现目标：用分块矩阵乘法模拟 NFU 的计算与缓冲行为，对比“不分块直接访存”与“分块复用”的访存次数。
- 要测量：MAC 数、权重/激活的 DRAM 读取次数、分块大小对复用率的影响、定点量化前后的误差。
- 不会与原文芯片一致的地方：周期数、面积、功耗、真实片上时序；本骨架只验证算法与数据流层面的正确性。
