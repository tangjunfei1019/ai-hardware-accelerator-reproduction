# ShiDianNao：将视觉处理移近传感器

## 原文信息

- 原文标题：ShiDianNao: Shifting Vision Processing Closer to the Sensor
- 作者：Zidong Du、Robert Fasthuber、Tianshi Chen 等
- 年份与发表处：2015，ISCA 2015

## 核心方法

- 核心思想：不要先把整幅图像搬到内存再算，而是把加速器直接连在视觉传感器旁边，数据一出传感器就进入计算流水线，绕过片外内存这一级。
- 适用场景是小模型视觉任务：当整个 CNN 参数能放进片上 SRAM 时，片外 DRAM 访问可以被大幅削减；对这类任务，传感器直连的收益最大。
- 架构上仍是 DianNao 家族的 NFU 与缓冲思想，但数据通路的起点从“内存”改成了“传感器”，存储层次随之简化。
- 设计取舍：牺牲通用性，换取嵌入式视觉的极低功耗与小面积。

## 核心效果

- 综述类文献转述：ShiDianNao 相对 DianNao 的能效提升可达约 60 倍量级（口径为特定视觉任务与对照条件，具体以原文为准）。
- 适用边界很关键：模型变大、放不进片上存储时，传感器直连的收益会迅速下降；这篇的结论不能直接推广到大模型。
- 面积方面，公开综述表格中给出约 4.86 mm²（65 nm）这一量级，具体以原文为准。

## 复现要点

- 复现目标：对比两种数据通路——“传感器→DRAM→加速器”与“传感器→加速器直连”——在小模型上的访存量与延迟。
- 要测量：DRAM 访问量、端到端延迟、片上 SRAM 容量需求随模型大小的变化。
- 不会与原文芯片一致的地方：真实传感器接口时序、模拟/数字边界功耗、芯片面积。
