# EVA：用向量量化加速大模型解码

## 原文信息

- 原文标题：EVA: Accelerating LLM Decoding via an Efficient Vector Quantization Architecture
- 中文标题：EVA：基于高效向量量化架构的大模型解码加速
- 作者：Bowen Duan、Cong Guo、Chiyue Wei、Haoxuan Shan、Yuzhe Fu、Xinhua Chen、Yifan Xu、Ziyue Zhang、Changchun Zhou、Hai Li、Yiran Chen（杜克大学）
- 年份与发表处：2026，ISCA 2026；arXiv:2605.24144

## 核心方法

- 权重向量量化：把权重矩阵按向量分组聚类为共享码本，权重只存低精度索引，可做到约 2 比特量级的权重压缩。
- 关键洞察：解码是访存受限的小 GEMV。EVA 不先把量化权重反量化还原，而是直接做输入向量与权重码本的点积，把解码从 GEMV 形态转为类 GEMM 的计算形态。
- 无冲突结构化查表：结合输入-码本计算与无冲突访存设计，解决查表架构常见的 bank 冲突问题。
- 软硬件协同：架构针对解码特化，同时兼容常规 prefill 执行，不是只做解码的孤立模块。

## 核心效果

- 论文报告（以原文摘要为准）：相对当时最优的查表架构，最高约 11.17 倍加速、约 7.17 倍能效提升，且在向量量化后保持算术精度。
- 意义：它把“量化压缩”从单纯省显存，变成了“改计算形态”的架构机会，是 2026 年解码加速路线中量化与架构结合最直接的一例。

## 复现要点

- 复现目标：构造小码本与权重索引，比较“先反量化再乘加”与“输入×码本点积再按索引求和”两种路径的结果一致性与访存量差异。
- 要测量：码本大小与索引位宽对压缩比的影响、两种路径的乘加次数与查表次数、量化误差。
- 不会与原文芯片一致的地方：真实码本学习（聚类训练）、无冲突访存硬件、片上存储层次与时钟功耗；骨架只验证计算等价性。
